# Page Image Downloader

현재 Chrome 탭에 표시된 이미지를 찾아 크기와 확장자로 필터링하고 일괄 다운로드하는 Manifest V3 확장프로그램입니다.

## 기능

- `<img>`, SVG `<image>`, CSS `background-image` 이미지 검색
- 썸네일형/목록형 보기 전환
- 가로·세로 최소/최대 크기 필터
- 확장자 복수 선택 필터
- 전체 선택 및 다중 다운로드
- 공통 base 이름과 순번을 적용한 파일명 생성

## 설치

1. GitHub Releases에서 ZIP 파일을 내려받아 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축을 푼 폴더를 선택합니다.

## 사용

1. 이미지를 받을 웹페이지를 엽니다.
2. 툴바의 확장프로그램 아이콘을 누릅니다.
3. 크기/확장자 필터를 지정하고 이미지를 선택합니다.
4. 필요하면 공통 파일명을 입력한 뒤 다운로드합니다.

공통 파일명이 `product`이고 12개를 선택하면 `product-01.jpg`, `product-02.png`처럼 저장됩니다. 공통 파일명을 비우면 원래 파일명을 사용합니다.

## 제한 사항

- Chrome 내부 페이지(`chrome://`)와 Chrome Web Store에서는 보안 정책상 실행할 수 없습니다.
- CSS 배경 이미지의 크기는 원본 픽셀 대신 화면에 표시된 영역을 기준으로 수집될 수 있습니다.
- 로그인·Referer·쿠키 정책으로 직접 접근이 차단된 일부 이미지는 다운로드가 실패할 수 있습니다.
