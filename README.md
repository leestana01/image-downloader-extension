# Page Image Downloader

현재 Chrome 탭에 표시된 이미지를 찾아 크기와 확장자로 필터링하고 일괄 다운로드하는 Manifest V3 확장프로그램입니다.

## 기능

- `<img>`, SVG `<image>`, CSS `background-image` 이미지 검색
- 기본 확장프로그램 팝업과 선택형 독립 창·새 탭·전체화면
- 가상 스크롤에서 사라진 이미지 URL을 보존하는 ON/OFF 수집 모드
- 썸네일형/목록형 보기 전환
- 가로·세로 최소/최대 크기 필터
- 확장자 복수 선택 필터
- 전체 선택 및 개별/ZIP 다중 다운로드
- `공통이름_순서.확장자` 규칙의 파일명 생성

## 설치

1. GitHub Releases에서 ZIP 파일을 내려받아 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축을 푼 폴더를 선택합니다.

## 사용

1. 이미지를 받을 웹페이지를 엽니다.
2. 툴바의 확장프로그램 아이콘을 누릅니다.
3. 크기/확장자 필터를 지정하고 이미지를 선택합니다.
4. 필요하면 공통 파일명을 입력한 뒤 다운로드합니다.

확장프로그램 아이콘을 누르면 기본 팝업이 열립니다. 우측 상단 버튼으로 크기 조절 가능한 독립 창, 새 탭 또는 전체화면을 선택할 수 있습니다. Chrome 기본 팝업 자체는 브라우저 정책상 테두리 드래그 리사이즈를 지원하지 않습니다.

공통 파일명이 `product`이고 12개를 선택하면 `product_01.jpg`, `product_02.png`처럼 저장됩니다. 공통 파일명을 비우면 원래 파일명을 사용합니다. 하단에서 개별 파일 또는 단일 ZIP 파일 다운로드를 선택할 수 있습니다.

가상 스크롤 사이트에서는 이미지를 보기 전에 **수집 모드**를 켜고 페이지를 스크롤합니다. 화면에서 제거된 이미지도 탭을 새로고침하거나 닫기 전까지 누적 목록에 유지됩니다. 수집 모드를 끄면 새 이미지 관찰만 중단되고 기존 수집 결과는 유지됩니다.

## 제한 사항

- Chrome 내부 페이지(`chrome://`)와 Chrome Web Store에서는 보안 정책상 실행할 수 없습니다.
- CSS 배경 이미지의 크기는 원본 픽셀 대신 화면에 표시된 영역을 기준으로 수집될 수 있습니다.
- 로그인·Referer·쿠키 정책으로 직접 접근이 차단된 일부 이미지는 다운로드가 실패할 수 있습니다.
- 개별 다운로드도 이미지 데이터를 먼저 가져온 뒤 지정 파일명으로 저장하므로 서버의 원본 파일명 헤더에 덮어쓰이지 않습니다.
- ZIP 생성은 선택한 이미지를 메모리에 모아서 처리하므로 대용량 이미지를 많이 선택하면 시간이 걸릴 수 있습니다.
